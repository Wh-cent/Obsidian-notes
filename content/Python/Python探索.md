

# `name` = `vincent`的理解
*困惑：编程中的对象意味着字典一样的数据结构？难道不是指函数中的实参吗？但是可以理解为变量的东西都可以认为是对象，这说明变量就相当于字典吗？字典的本质是什么？*

字典是数据结构，保存键值对；编程中的对象Object有很多类，比如整数对象、字符串对象、函数对象，不同的类型决定了可以进行什么操作

即：字典是一种对象，但对象并不是字典；换句话说，我个人认为，对象更像是字典键值对的值`Value`，而键值对的`keyword`便是变量 —— 一个可以指向不同对象的名称
```python
name = 'vincent'
```
`name`即变量名，`vincent`即字符串对象，`name`指向`vincent`

补：对象也可分类，分类依据也很多，比如可迭代与不可迭代




迭代器【iterator】，装饰器【decorator】，生成器【generator】都是一种装置，像是一种工具性的系统

generator 生成器函数
generator() 是在调用生成器函数，并得到一个生成器对象
g = generator() 是指向该对象的变量名
g.send 是提供的一种方法
g.send() 是在调用这个方法
